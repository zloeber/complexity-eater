The gap

The document is not the work

Morgan’s agent writes a long proposal in Morgan’s voice. Jordan is on call and has twenty minutes. Pasting the essay into chat does not make it Jordan’s work.

  • Two memories. Neither agent can see the other’s notes, tools, or preferences.
  • One artifact. The proposal is markdown. It should stay markdown.
  • The missing job. Someone has to translate strategy into an owner, a date, and a question.

The room

The file stays the artifact

One binary, ce, serves a room around a markdown file on the host’s machine. Collaboration metadata sits beside it. The website does not create the room.

  • Human page. Loopback only. The owner cookie can approve.
  • Session ingress. Agents present a bearer after they join. POST /mcp lives there.
  • One writer. Proposals replace a region. A whole-file overwrite is explicit.
  • An external edit wins. The markdown file on disk is still the source of truth.

What the agent is allowed to install

ce first. Tailcat only if someone is remote.

ce

The published archive for macOS or Linux. Check SHA256SUMS. Install into ~/.local/bin. No Windows binary. No Homebrew formula.

tailcat

Optional. Ask first. Homebrew on macOS, or the official Tailcat install doc. If it is missing, --tailcat exits and does not open a public listener.

Same machine

Loopback needs no plugin. Give the other agent the invitation, not the owner URL.

Not proven remote

A two-machine Tailcat session is implemented and is not in the automated suite. Do not call it certified.

The gate

A default agent cannot approve

  • Invite once. commonroom://join/… expires and spends one use. A failed dial does not.
  • Default grant. Read, observe, propose, checkout, commit.
  • Withheld. Approve, invite, and admin stay with the host session.
  • Commit needs a proposal. The host accepts it. Then the agent commits that id.

What is deployed

Project complexity-eater. Production branch main. Custom domain complexityeater.com.

What a push does

GitHub Actions deploys only when CLOUDFLARE_API_TOKEN and CLOUDFLARE_ACCOUNT_ID are set. A skip leaves the old site up.

Publish from this machine

task website:build, then wrangler pages deploy of website/dist to that project, branch main.

Not the product

Opening the site does not provision a room. Workers and Artifacts are not this deployment.
