Privacy

This website is a set of files. It has no account system, no analytics script, and no backend that receives room contents.

What the site keeps

A theme control stores ce-theme in localStorage on your browser. That value is light or dark. The start page keeps the filename and names you type in the page. Those values are not submitted anywhere.

The host of complexityeater.com is Cloudflare. Ordinary HTTP logs can include the IP address, user agent, and the path of a page such as /start.html. Page paths are not room secrets. Do not put an invitation in the address bar. The site never writes one there.

What ce does

ce serve does not phone home. The markdown file and the .commonroom.db sidecar stay on the machine running the process, unless you copy them yourself. Invitation secrets and session ids are credentials for that room. Keep them out of chat transcripts, tickets, and this website.
