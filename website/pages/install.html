Check the download

Download SHA256SUMS beside the archive, then check the file you fetched. On macOS:

grep ce-macos-aarch64.tar.gz SHA256SUMS | shasum -a 256 -c -
tar -xzf ce-macos-aarch64.tar.gz
chmod 755 ce

On Linux, use sha256sum -c with the matching line. The checksum file also lists SBOMs and the image digest. You only need the line for the archive you downloaded.

The checksum shows the archive matches the release. It does not show who published it. Verify the GitHub artifact attestation for the archive you downloaded:

gh attestation verify ce-macos-aarch64.tar.gz -R zloeber/complexity-eater

Use the archive name for your system in place of ce-macos-aarch64.tar.gz.

Container image

The scanned image for this release is {{release.image}}. The published digest file records:

{{release.image_digest}}  {{release.image}}

That line is copied from image-digest.txt on the release. The image runs as UID 65532 and binds loopback. Docker Desktop on macOS does not attach that listener to the Mac's loopback. On a Mac, run the binary directly. The container profile is in the container notes.

Build from source

The toolchain is Rust {{toolchain}}, pinned in rust-toolchain.toml. Supported development platforms are macOS and Linux.

task setup
task release

task release writes target/release/ce. task build writes the debug binary to target/debug/ce. ce --version prints the package version.
