Short answers

FAQ

Does this website create a room?
No. The website is static. A room exists when you run ce on a machine that has the markdown file.
Where does the markdown file live?
On the host that runs ce. The website has no upload control. Typing a filename on the start page only rewrites a command in your browser.
What should I give an agent?
The invitation printed by the room, commonroom://join/…. Do not give out the owner URL or a raw transport address. Do not paste the invitation into this site.
Can the agent approve its own edit?
A default invitation cannot. The host session can approve. The agent can commit a proposal that is already approved.
What happens if Tailcat is not installed?
ce exits with transport_unavailable. It does not fall back to a public listener. Loopback still works without Tailcat.
Does ce serve phone home?
No. Local mode has no account, no license check, and no telemetry.
What does --ephemeral delete?
The temporary directory that holds the sidecar, when the process exits. The markdown file stays where it is. Deletion is not a promise that the underlying disk blocks were wiped.
Which platforms have binaries?
The v0.2.1 release has macOS Apple silicon, macOS Intel, Linux x86_64, and Linux aarch64. Windows paths exist for configuration directories. A Windows binary is not published. Homebrew is not packaged yet.
Is a remote Tailcat session proven?
The plugin is implemented. A two-machine Tailcat session is not part of the automated test suite. Do not treat that path as certified by CI.
When will hosted rooms exist?
They are not implemented. The proposal compares a remote ce process, a shared supervisor, and a Workers port, and recommends starting from the binary that already exists.
