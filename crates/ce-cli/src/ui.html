    Remote adapter

    Cloudflare Tunnel

    Traffic for a quick tunnel goes through Cloudflare. HTTPS on that hostname is not a private network and does not authorize an agent. Workspace access stays an invitation.

    This page does not install cloudflared, call the Cloudflare API, change DNS, or install an operating-system service. A named tunnel needs a Cloudflare account and a certificate created by cloudflared tunnel login outside this page. Do not paste that certificate or an API token here.

    The origin is always http://127.0.0.1 on that port. The management page is a different port and is not published. Point this at the room's session ingress, then start the room before starting the tunnel.

    1. Install cloudflared from Cloudflare's documented downloads. Come back and reload.
    2. For a named tunnel, run cloudflared tunnel login, cloudflared tunnel create NAME, and cloudflared tunnel route dns NAME HOST yourself. Those commands can create account resources.
    3. Optional Access policy: configure it in the Cloudflare dashboard. This application ignores Cf-Access-Jwt-Assertion and Cf-Access-Authenticated-User-Email.
    4. Confirm, save, then start. The process is a child of ce ui. Stop ends that child. Disable also clears the local preference.

    After disable, a named tunnel, its DNS record, and the cloudflared login certificate remain in your Cloudflare account until you delete them there. The markdown file and sidecar stay here either way. Quick-tunnel hostnames stop working when the child stops. Plan limits and pricing are Cloudflare's, not this application's.

    Private network

    Tailcat is optional. This page does not install or start it. A missing plugin is transport_unavailable. The room still refuses a non-loopback bind. Publish with ce serve notes.md --tailcat after you install the plugin. A connected plugin is not a participant.

    Invitations

    A tunnel, a plugin, or a URL does not join a workspace. Create a one-use invitation with the default agent capabilities. It cannot approve. Revoke it here, or end a participant from the room.

    The invitation string is shown once and is omitted from diagnostics.
