# Five-minute demo

Open https://complexity-eater-handoff.zloeber.workers.dev in the presenter browser. Keep a private window ready for the recipient. The sample document is the whole script. Do not connect a model provider.

## 0:00 — Two people, two agents

Say: Avery Chen is an engineering manager. Jordan Hale is the engineer who has to act on Avery's proposal. Each person keeps their own agent. Complexity Eater only carries the markdown Avery chose to hand over.

The amber banner says the agents are simulated. The blue banner names the Worker and, on this account, Durable Object storage.

## 0:45 — Create the handoff

Leave sender **Avery Chen** and recipient **Jordan Hale**. The box already holds the checkout-retry proposal. Click **Create handoff**.

Point at the left column. That is Avery's original, with a revision id. Jordan's side says the original is sealed and Jordan's agent has not opened it. Avery does not see Jordan's private notes, because they were never in the handoff.

## 1:30 — Invite Jordan

Click **Create invitation**. Copy the link. It looks like `/h/h...#invite=...`. The code is in the fragment. It is not a query parameter. It works once, expires in 60 minutes, and **Revoke invitation** kills it.

## 2:00 — Jordan's agent reads it

Paste the link into a private window. The fragment is removed from the address bar after redeem.

Jordan's column leads with action items, then questions, then dependencies. The summary is concrete work, not a status report. The boundary line says this reading used the handoff text and Jordan's demo profile only.

Switch **Read the same original as** to Riley Okonkwo. The preview leads with scope. The banner says the preview is not stored. Switch back to Jordan Hale. The stored reading is Jordan's again. The left column has not changed.

## 3:30 — Send the return

The reply box is already a draft in Jordan's voice: the actions, the blocking questions, and a date. Edit one line if you want it to sound like the employee. Click **Send response back**.

## 4:15 — Avery receives it

Return to Avery's window. The status becomes **Return handoff sent**. Below the two columns, Avery sees Jordan's response unchanged, then Avery's own reading of that response: decision, date, and the blocking question.

Click **Acknowledge return**. The revision list grows, and the first revision is still **Seal original handoff**. Later lines do not rewrite that file.

## 4:45 — Why this is less coordination

Avery did not rewrite the proposal into Jordan's task system. Jordan did not read Avery's calendar or finance thread. The original, the personalized reading, the questions, and the return are on one page, and the return is already in the form Avery uses.

**New handoff** starts the same sample again.
